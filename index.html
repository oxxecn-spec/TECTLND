How to Measure Screens & Folding Doors

Windows (All Types)

Measure width at top, middle, bottom — use the smallest. Measure height on both sides, use the smallest.

Patio & Balcony Doors

Measure full opening width and height. For folding doors, measure each panel if specified.

Non-Standard Shapes

Arched, round, or triangular? Send a photo with measurements — we'll design a perfect fit.

Entry Folding & Pet-Proof Doors

Measure the full door frame. Note heavy-duty track requirements if applicable.
